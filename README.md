# Adrenaline_404 Showcase  
Xiaomi SM6225 / Snapdragon 685 Tools

Halaman statis ini adalah showcase sederhana yang menampilkan **tiga tools performa untuk perangkat Xiaomi/POCO/Redmi berbasis Snapdragon 685 (SM6225)**

### Cara Melihat Showcase

1. Clone atau download repository ini  
2. Buka file `index.html` langsung di browser (tidak perlu server)  
   - Double-click file  
   - Atau gunakan VS Code Live Server  
   - Atau drag file ke tab browser

### Teknologi Showcase

- HTML5  
- CSS3 (custom styling)  
- Google Fonts: JetBrains Mono & Orbitron  

Tidak ada framework, JavaScript rumit, atau backend.
